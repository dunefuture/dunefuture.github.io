# Dune Future Website

A free static website for the Dune Future Discord community.

## Preview locally
Open `index.html` in your browser.

## Add your Discord invite
Open `index.html`, find:
    id="discord" href="#"
Replace `#` with your Discord invite URL and remove:
    onclick="return missingInvite()"

## Publish free with GitHub Pages
1. Create a GitHub account/repository.
2. Upload index.html, style.css and script.js.
3. In repository Settings > Pages, deploy from the main branch.
4. GitHub will provide your free public URL.

You can also deploy the same files to Cloudflare Pages.
